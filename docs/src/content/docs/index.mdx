<div class="feature-strip">
  <div class="feature-item">
    <span class="feature-key">stack</span>
    <span class="feature-label">Every instruction is checked against a typed model of the evaluation stack before it is accepted. Underflows show up at the prompt.</span>
  </div>
  <div class="feature-item">
    <span class="feature-key">ret</span>
    <span class="feature-label">The cell compiles with Reflection.Emit and runs on the JIT. What you see is what the runtime did.</span>
  </div>
  <div class="feature-item">
    <span class="feature-key">all of IL</span>
    <span class="feature-label">Every opcode, exception blocks, calli, varargs, pinned locals, cell arguments, generic parameters, tokens.</span>
  </div>
  <div class="feature-item">
    <span class="feature-key">.save</span>
    <span class="feature-label">Write a cell to disk as a real assembly, or read it back as ILAsm with .il.</span>
  </div>
</div>
