Click into the terminal and type. Enter continues a block while its braces are open and sends it once they balance, so a method is typed or pasted in one go. Tab completes opcodes, types, and members. Up and Down choose matches while the palette is open; otherwise they move through the buffer and reach history at its ends. History stays in this browser between visits, and `.help` lists the commands. Drag across the transcript to select text and press y, Cmd+C, or Ctrl+C to copy it.

Open, Download, and Share keep your experiment as editable source. Opening a file or link does not run it; use Run all when ready.
Ctrl+S downloads and Ctrl+O opens the file picker while the terminal has focus.
Downloads include available dependency images; `--embed` is already applied here. Package restore and project builds
require ilrepl in a terminal. `.save example.dll` downloads an assembly without running it. The browser chooses its location;
a directory in the supplied name does not select a folder on your computer.

Share links contain source and dependency images, including the bundled sample. Nothing is uploaded to the documentation server.
Links longer than 16 KiB fall back to a session download. Expanded links are limited to 1 MiB and imported files to 8 MiB.
Session files created in the terminal can be up to 64 MiB. If clipboard access is unavailable, the page displays the link for copying.

Ctrl+Q and the restart button end the session and start a fresh one in its place, without the previous source or history.
If a cell stops responding, the page replaces the runtime and reopens the source and editor draft without executing them.
Previous results remain historical text, and objects and static values are lost. The old runtime stops before its replacement
starts. Input typed meanwhile stays in the editor, where Enter adds a line. Press Enter again once the session is ready.
See [Saving and sharing sessions](/usage/sessions/) for the terminal's session commands and dependency handling.
